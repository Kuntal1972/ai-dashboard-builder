⚙️ SETUP — TWO OPERATING MODES
🤖 Claude API Mode (Browser-Direct, Paid)
No server needed. Browser calls Claude API directly via key.
🔑 Get key: console.anthropic.com
➡ Enter key in ⚙ Settings panel of app
➡ Click 🤖 Claude API Mode button in header
✅ Supports all 33 chart types + full column resolution

🖱️ BUTTONS & THEIR ACTIONS
📌 Header Toolbar Buttons
⬆️ Upload File

Opens file picker → accepts CSV, XLSX, XLS. Auto-parses columns, detects types (number/string/date), shows data preview in Data tab

✨ Generate Prompt

Scans dataset columns → auto-builds full KPI + chart prompt filled into prompt text box instantly

📖 Prompt Guide

Opens overlay panel with example prompts, column tips, and chart-type guidance

⬇️ Download HTML

Exports full interactive dashboard as self-contained HTML (Plotly.js embedded — opens in any browser)

📥 Download Excel

Exports filtered dataset + chart aggregations as multi-sheet .xlsx workbook

🔍 Debug

Toggles column mapping inspector — shows exactly how each column was resolved for each chart

🗑️ Clear Dashboard

Removes all rendered charts and KPI cards — dataset stays loaded for re-use

⚙️ Settings

Claude API key, model selector, colour palette, histogram bins, export resolution

⚡ Prompt Area Buttons
⚡ Build Dashboard

Sends prompt + dataset to AI engine → renders full dashboard: KPI cards, charts, filters all at once

🔄 Refine

Sends follow-up prompt to modify existing dashboard — add/change/remove specific charts without full rebuild

📊 Charts Tab Buttons
⊞ Select All Charts

Appends dataset-aware smart prompt lines for ALL 33 chart types simultaneously into prompt box

⧉ Add Filters

Scans dataset for categorical (≤25 unique) + date columns → appends slicer/filter prompt line

📊 [Chart Type Card]

Each card click appends ONE smart prompt line e.g. – Bar chart showing Revenue by Region

📁 Data Tab
⟷ Map & Join Tables

Opens join dialog when 2+ files uploaded → select matching key columns → merges into one flat dataset

🔽 Filter Controls

Dropdown slicers, date range pickers — clicking any filter updates all dashboard charts live instantly

🔗 MULTI-DATASET JOIN
1
📂 Upload first file — CSV or XLSX appears in Data tab with column preview
2
📂 Upload second file — ⟷ Map & Join Tables button appears automatically in header
3
🖱 Click Map & Join → dialog opens showing both tables with their columns listed
4
🔑 Select join key columns — e.g. OrderID (Table A) ↔ Order_ID (Table B)
5
⚙ Choose join type — Inner / Left / Outer merge operation
6
✅ Confirm → merged flat dataset replaces active dataset; all columns from both tables available
💡 Tip: Up to 3 files can be chained. Duplicate column names get auto-suffixed _A / _B. Use the Data tab to preview merged result before prompting.
✏️ WRITING & GENERATING PROMPTS
📝 3 Ways to Create a Prompt
A
✍ Manual: Type directly in the large prompt text area using plain English — describe charts, KPIs, and filters needed.
B
✨ Generate Prompt button: Scans column names & types → auto-writes a full dashboard prompt with KPIs, 8 chart suggestions, filter line, + Box & Whisker and Marimekko at end.
C
📊 Chart Cards / ⊞ Select All: Each chart card click appends one smart prompt line. Select All appends all 33 types at once.
💬 Sample Prompt Format
Create a Sales Dashboard with:
– KPI cards for total Revenue, avg Margin, count of Orders
– 📊 Bar chart for Revenue by Region
– 📈 Line chart for Revenue trend over OrderDate
– 🥧 Pie chart for Revenue share by Category
– 📦 Box and Whisker Plot showing UnitPrice by PaymentMethod
– ▦ Marimekko chart of Revenue by Category and OrderStatus
– 🔽 Filters for Region, Category, OrderDate
💡 Prompt Tips
  • 🎯 Use exact column names for precise matching
  • 📐 Specify aggregation: total, average, count
  • 🔝 Add top 10, by date, split by, colored by
  • 🔄 Use Refine button to modify without full rebuild
  • 📌 Separate chart requests with – prefix per line
📥 DOWNLOAD & EXPORT FORMATS
📊 .pbit — Power BI Template

Full Power BI Template file. Double-click opens in Power BI Desktop. Embedded data model, DAX measures, all visual layouts. Power BI + Ollama mode only.

🌐 Download HTML

Self-contained interactive HTML file with all charts (Plotly.js embedded). Opens in any browser, no server needed. Shareable via email or cloud drive.

📥 Download Excel (.xlsx)

Current filtered dataset exported as multi-sheet Excel workbook: raw data + per-chart aggregated summary tables.

🖼️ Chart PNG (per chart)

Each chart has a 📷 camera icon in its Plotly toolbar → exports that individual chart as high-resolution PNG (1400×700px).

📋 CSV (via table copy)

Right-click any Data Table chart on dashboard → select all / copy → paste directly into Excel or text editor.

🚀 Deploy to Render.com (Free Tier)
1
🔼 Push code: git push origin main to GitHub
2
🌐 Login to render.com → New → Web Service
3
🔗 Connect GitHub repo → Select branch main
4
⚙ Build: npm install  |  Start: node server/index.js
5
🔑 Add Env Vars: GROQ_API_KEY (for cloud LLM)
6
✅ Deploy → get live URL: yourapp.onrender.com
⚠️ Important: Ollama cannot run on Render.com (no GPU/local). For cloud deployment use Groq API key as the LLM provider instead. Set GROQ_API_KEY as an environment variable in the Render dashboard.
